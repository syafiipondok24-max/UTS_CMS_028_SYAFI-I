TEMA WORDPRESS: SYAFII STARTER

ISI FOLDER
- style.css      : identitas tema dan seluruh aturan tampilan/CSS
- functions.php  : fitur tema, menu, thumbnail, dan pemanggilan CSS
- header.php     : bagian kepala situs dan menu navigasi
- footer.php     : bagian kaki situs
- front-page.php : halaman depan
- index.php      : daftar artikel dan template cadangan
- single.php     : halaman detail satu artikel
- page.php       : halaman statis
- archive.php    : arsip kategori/tanggal
- sidebar.php    : widget informasi, artikel terbaru, kategori, pencarian

CARA MEMASANG
1. Ekstrak folder tema ini ke:
   wp-content/themes/syafii-starter
2. Buka Dashboard WordPress > Tampilan > Tema.
3. Aktifkan tema "Syafii Starter".
4. Buka Tampilan > Menu, buat menu baru, centang lokasi "Menu Utama".
5. Buka Pos > Tambah Pos untuk membuat beberapa artikel.
6. Saat menulis artikel, tambahkan Gambar Unggulan agar kartu artikel memiliki gambar.
7. Buka Pengaturan > Membaca untuk menentukan halaman depan bila ingin memakai halaman statis.
8. Uji tampilan di desktop dan ponsel.

CATATAN
- Tema ini dibuat sebagai starter untuk pembelajaran, bukan tema produksi final.
- Jangan menghapus wp_head() di header.php atau wp_footer() di footer.php.
- Gunakan hanya gambar dan tulisan yang kamu miliki atau punya izin untuk digunakan.
